# 出片

## 渲染

先完成 `shot_final.blend`，从根目录安装 requirements。执行 README 的 `init`，它会读取真实工程参数并生成独立配置。查看 `inspection.json`，特别是没有 UV 的网格、缺图、外链和脚本不能自动判断的项。

`run` 只接续已验证的帧；输入改变进入新代次。中断后使用相同命令恢复。初始化与运行时的磁盘保留量通过命令参数指定，不照抄其他机器容量。

## 后期与声音

先看原生序列是否已经足够。调色、光晕、超分和插帧都用同一短段比较收益与伪影，决定采用后再扩展整片；无收益可以直接编码。

声音可以在 Blender 的 Video Sequencer 中编辑：添加渲染图序列和有使用权限的音频，保持相同帧率，按切点同步并检查头尾。输出编码选择 FFmpeg Video、MPEG-4、H.264 与 AAC；实际设置取决于交付要求。

也可以使用 `encode` 产生无声预览后，用 FFmpeg 合成已剪好的音轨：

```sh
ffmpeg -i preview.mp4 -i soundtrack.wav -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k -movflags +faststart film.mp4
```

音轨先剪到目标时长；不要依靠 `-shortest` 静默截掉片尾。此示例没有自动做音画同步，合成后完整审听。

## 交付检查

核对实际尺寸、帧率、解码帧数和音轨；正常速度看全片，检查角色是否连续存在、闪烁、穿插、边缘、表情、切点与声音。技术通过和美术采用分别记录。

保留工程、图片／控制图源文件、动作、缓存恢复方法、配置、视频和来源表。借物表按最终成片实际依赖列模型、动作／表情、镜头、场景、材质／工具、音乐；未知项补查，不把替换候选的状态写成原成片状态。
