# 渲染控制

## 相机与灯光

先确定画幅和角色在画面中的大小。Camera 视图检查脸、手势和轮廓，使用焦距与相机距离控制透视，不只靠裁切。

先建立主光、必要补光和背景分离，观察脸与银发等亮部是否保留层次。卡通材质内的光向若不是自动跟随实体灯，需要同步或建立对应驱动。额外环境色以实际收益决定。

## 显示与材质

先固定 Color Management 的 View Transform、曝光和显示设备，再比较材质。后期使用相同色彩解释。不要依靠后期曝光掩盖错误的输入颜色空间或控制图。

## 输出

Output Properties 设置分辨率、帧率与起止帧；先输出 PNG 序列，完整验证后再编码视频。EEVEE 与 Cycles 的节点能力不同，Shader to RGB 等特性需在匹配的渲染器使用。

先渲一张代表性静帧，再出能暴露运动问题的短样，最后完整序列。采样按实际噪声、透明层和运动需要调整；采样更高不会修正错误轮廓、UV 或神态。

## 冻结工程

另存 `shot_final.blend`；记录真实帧区间、帧率、显示设置、贴图和物理缓存。重开文件检查相机、当前动作、材质输出和依赖。之后用出片入口执行，不把尚未检查的候选直接覆盖采用版本。
