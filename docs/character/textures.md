# UV 与贴图

## 建立语义表

先列出材质实际需要的图片：颜色、阴影阈值、镜面范围、金属域、法线、透明和表情。控制图每个通道按照所用着色器文档解释，不按颜色外观猜用途。

颜色图通常用 sRGB；控制／数值图按着色器要求设 Non-Color。以实际接口为准，不能因为某图看着灰就自行改为数据图。

## UV

UV Editing 中打开棋盘格，检查眼睛、脸颊、发根、接缝和衣饰是否拉伸。脸眼等特写区域需要足够像素密度；使用独立图集或增加该区域 UV 面积，比单纯把整张图插值放大有效。

重排前保存原 UV。已有动作／表情或共用材质时，先在副本迁移贴图并检查全部关联部件。UV 边界之外留足采样扩边，避免缩小与远景出现接缝。

## 绘制

- 脸：保留干净的皮肤色、适量的腮红与眼周关系；不要把当前灯光下的深阴影画死。
- 眼：保持虹膜／瞳孔形状，使用连续圆润边界和有层次的颜色，检查原尺寸而非只看放大图。
- 头发：按每束 UV 走向组织明暗和色阶，避免无意义横线、硬折和重复纹理。前／侧／背统一观察。
- 衣饰：颜色设计与金属／镜面控制分开，图案按实际设计制作，不借反光控制图偷偷引入装饰。

保留带图层源文件；导出图能重新生成。16 位数据图仅在实际生成器、节点和文件格式都保留精度时有意义；颜色图更大也不自动等于更清晰。

## 完成检查

贴回工程，同相机看整幅和原像素局部，补侧面／背面、闭眼和接缝。若仍有锯齿，分别核查源像素、UV 密度、采样、几何和描边，不把所有问题交给超分。
