# 角色资产

## 输入

官方实机截图、角色设计目标；AI 生成的 GLB，或可以修改使用的现有角色模型。保留原文件，第一次导入另存 `character_base.blend`。

## AI 基础模型

1. 准备清楚、无遮挡、肢体不过度交叠的输入图；正面与侧面设计应一致。生成用图与最终目标图分别存放。
2. 在生成工具中先比较轮廓、体块和衣饰位置。眼睛画在表面、头发糊成整体、手指粘连时，把对应部分列为重建项。
3. 导出 GLB，同时保存输入图、生成参数、模型版本和随机种子（工具可取得时）。不要只保存预览截图。
4. Blender 中 File → Import → glTF 2.0。分别检查模型、材质、贴图是否实际导入；AI 输出有 PBR 材质不代表已适合卡通风格。

## 已有模型

PMX 用 MMD Tools 导入；GLB 用原生导入。先检查骨架、形态键、材质槽、透明层和刚体。导入后暂不整体合并网格、不随意应用骨架修改器、不覆盖原 UV。

## 统一项目

- Scene Properties → Units 设置合适单位，用已知角色身高核对实际尺寸。
- 分别命名 Body、Face、Eyes、HairFront、HairSide、HairBack、Clothes、Accessories 与 Armature；名字是管理辅助，实际材质和面域仍需确认。
- 清点颜色图、控制图、脸影图、法线、反射数据。记录每张图的实际作用与颜色空间。
- File → External Data → Find Missing Files 定位外链；准备交接时可 Pack Resources。动画依赖和模拟缓存要另外保留，打包图片不等于打包全部依赖。

## 完成检查

重开保存副本，正面／侧面／背面检查轮廓；确认无缺图，骨架和形态键仍可用。输出一张中性灯光静帧作为改模前基线。
