# 物理

## 分配职责

先看当前模型是否已有 MMD 刚体／关节。保留有效原生设置；需要另一种次级运动工具时，先在一条发束或一片裙摆上验证，避免同一骨链同时受两个系统驱动。

## 调整顺序

1. 核对模型单位、骨链朝向、碰撞体位置和静止姿态。起始穿插先修模型／碰撞关系。
2. 暂停其他部件，调整根部跟随、末端延迟、阻尼和回弹。发根稳定，发梢允许摆动。
3. 添加需要的头部、肩颈、胸背、手臂碰撞，检查刚体是否误碰角色自身。
4. 用动作里的起停、转头和抬臂测试，检查穿插、抖动与伸长。单张静帧无法证明物理正常。
5. 参数稳定后烘焙并保存缓存。改动动作、单位或骨架后重新核对缓存依赖。

## 完成检查

从动画开始帧重置并连续播放；再从保存文件重开，以渲染实际读取的缓存验证。缓存路径与工程一起归档。不能把视口一次正常播放等同于后台渲染也已使用正确缓存。
