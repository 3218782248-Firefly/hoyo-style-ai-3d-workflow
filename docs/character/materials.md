# 材质

## 选择实现

先按上游说明建立可运行的通用卡通着色环境，再接角色。StellarToon 有自己的运行环境与依赖，具体版本是否能用于当前 Blender 必须验证；安装一个节点库不等于整个渲染方案已迁入。

本项目不打包角色专用预设或第三方节点源码。通用算法可按其许可使用，作者、版本、输入图与本地改动记录在来源表中。

## 材质分工

| 区域 | 主要职责 | 首先检查 |
|---|---|---|
| Body／衣饰 | 漫反射、分层阴影、金属与反光范围 | 通道是否正确、衣料与金属是否混为一体 |
| Face | 脸部阴影与鼻影、肤色、表情 | 头部光向、阴影阈值图、闭眼效果 |
| Eyes | 虹膜、眼白、高光与透明层 | 层间距离、排序、侧看轮廓 |
| Hair | 束向高光、受光色阶、叠压 | UV、法线、镜面域与光照响应 |
| Outline | 轮廓线与必要内线 | 屏幕线宽、发尖、遮挡与动态稳定 |

## Blender 中接入

Shader Editor 先定位 Material Output 的 Surface，再沿连线回溯。导入上游节点时明确替换范围，确认真正启用的分支。连线覆盖的输入不能靠修改默认值控制。

颜色图接颜色输入，控制图先按通道拆分。脸影输入应随头部方向与主光变化；头部矩阵、坐标轴、左右翻转必须用实际转头／换光小样确认。不同节点库的 LightMap 语义不能互换。

保留现有外观副本，先在一小部分材质上接入，静帧有收益再迁移其他区域。风格需要几何、UV、节点和贴图一起配合时可整体修改，但按组合结果判断。

## 完成检查

同机位、同灯光、同表情比较；再单独转头与换光。看正常整幅的清透、主次与神态，也看发尖、眼线、鼻影和饰件边缘。整体光泽应分布合理，不靠新增一条亮带制造油感。
