# 建模与改模

## 脸与眼

在正、侧视图放参考图，先调整头颅、下巴、面中和眼窝关系，再处理鼻嘴。对象模式选择网格，编辑模式配合比例编辑做小范围改形；有现成形态键时在副本上验证，避免改基形导致眨眼和表情破裂。

眼球、虹膜、眼白、眼线和高光层分开检查。眼睛的亮度不能靠把眼白整体提到过曝获得；眼线轮廓、虹膜层次、视线和眉形共同决定神态。至少检查正面、侧转、闭眼三个状态。

AI 网格面流不足时，先重建眼周、嘴周和需要变形的区域，再向其他区域拓展。Retopology 可用 Blender 的吸附／Shrinkwrap 配合手动拓扑；高模保留用于投射和对照。减面不会自动变成可表情的拓扑。

## 分束头发

先做刘海、包脸侧发、后脑和长发的主要叠压。可用曲线调整走向与宽度，或编辑有厚度的发片；在最终相机内看发根、发梢和束间空隙。

轮廓已认可时，先区分几何折角、法线折面、贴图硬边和描边；不一律增加细分。需要细分时保护发根、边界和饰件接触处，检查头发运动后是否开缝。

细节应服从束向：长线连续、宽窄有节奏、发梢收束。先建立大束和中束，再补必要细束。高密度短线容易让清晰度变成噪声。

## 衣饰、法线和变形

领口、袖口、饰件需要厚度和合理遮挡。Bevel 用于真正需要圆角的硬边，Solidify 用于薄片厚度；尺度要与模型实际尺寸一致。金边和印花若被修改器拉伸，先核对 UV 和材质分配。

使用 Data Transfer／Normal Edit 或上游材质推荐的法线处理前，保留原法线。比较同几何下的着色变化；不要用全头统一法线消掉已有发束体积。

## 完成检查

另存 `character_model.blend`。正侧背静帧、闭眼与嘴部表情、转头与抬臂检查通过后进入贴图。记录新增／改变的拓扑、UV、权重和形态键；纯材质改动不应意外改变它们。
