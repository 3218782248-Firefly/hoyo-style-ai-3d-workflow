# 表情与动作

## 绑定与权重

AI 模型没有可靠骨架时先完成拓扑，再用 Blender 原生骨架或合适的成熟绑定工具。绑定前核对单位和变换；自动权重后，必须测试肩、肘、腕、髋、膝和头颈，修正跨部件串权重。

已有 PMX 骨架通过 MMD Tools 保留结构导入；VMD 动作导入后核对帧率与骨名映射。陌生骨架先做一段重定向，不直接烘焙整片。

## 表情

先做／检查 Blink、LookLeft/Right、嘴部和眉毛形态键。每个键检查 0、0.5、1，特别是眼线与眼球遮挡。组合键不应让眼睑翻面、牙齿穿出或口腔漏光。

动作预设可能带表情曲线。先确认当前神态来自哪条曲线，调整动作段内的表情，不用永久改基形抵消某一帧神态。

## 一个短片练习

先用 24fps 的六秒镜头：0–1.5 秒建立视线，1.5–4 秒转头／抬手回应，4–6 秒收势。Timeline 设置 1–144 帧，姿态先看几个关键点，再在 Dope Sheet／Graph Editor 调整节奏与缓入缓出。

相机、眼神、头部与手势共同组织注意力。先用低分辨率播放看节奏，检查脚滑、手指、眨眼、相机切点和最后停留。这个练习的时间安排可改，不是所有角色的固定动作模板。

## 完成检查

保存 `shot_animation.blend`，正常速度检查完整动作，并查看抬臂、转头、闭眼等关键姿态。动作来源、修改和表情来源分别记录。
